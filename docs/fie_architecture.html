Complete System Architecture · v1.13.0 · 12-Layer Parallel Detection · LangGraph Pipeline · Feedback Loop · Streaming Interception

The whole system in five steps
New here? Read this strip first. FIE sits between your users and your AI model. It checks every prompt going in, lets safe ones reach your model, and checks every answer coming out — all explained below. The full technical map follows underneath.
📥
1 · A prompt arrives
A user sends a prompt through one line of code — the @monitor() decorator or the REST API.
→
🛡️
2 · The guard screens it
12 detectors run at once in under 20ms. Obvious attacks are blocked before your model ever sees them.
→
🤖
3 · Your model answers
Safe prompts pass straight through to your LLM. The answer goes back to the user with no delay.
→
🔬
4 · The answer is checked
In the background, 3 shadow models + an AI jury catch hallucinations. No added latency for the user.
→
🏷️
5 · A verdict + learning
Every request ends as VALIDATED, CORRECTED, or BLOCKED — and confirmed attacks are remembered for next time.

🔁 Feedback Loop Flow
1. Detection event fires (CLEAR ATTACK or output flag)

2. feedback_store.record() → MongoDB + JSONL

3. Reviewer: POST /flags/{id}/label
   {"label":"true_positive"}

4. apply_label() adds SHA-256(prompt) to
   _KNOWN_ATTACK_HASHES instantly

5. Next identical prompt → blocked in
   microseconds, skips all 12 layers

6. Server restart → _load_confirmed_from_db()
   rebuilds sets from MongoDB
⚙ Key Design Decisions
11 parallel layers
Total latency = slowest, not sum

Feedback fast-path
O(1) hash — no model inference for confirmed attacks

Fail-secure UNCERTAIN
LG outage degrades precision, not security

400-char stream buffer
Catches policy-echo without destroying streaming UX

Fire-and-forget emails
SendGrid outage never causes request failures

Two explainability modes
Internal mode for operators, external hides
threshold values from attackers

Domain multipliers
One knob per domain — same detection logic,
different risk tolerance
🧠 Explanation Modes
Internal mode (operators/audit):
Full SHAP values · raw matched text
Specific threshold values · all signals

External mode (end users):
Outcome labels only · no thresholds
safe_to_expose=True signals only
Hides detection mechanics from attackers

Confidence formula:
0.25×jury + 0.20×evidence + 0.20×signals
+ 0.20×fix + 0.15×source − penalties
📊 Three Outcomes + MongoDB Persistence
VALIDATED: primary model confirmed correct by shadow jury · CORRECTED: hallucination detected, shadow consensus replaces primary response · BLOCKED: adversarial attack intercepted before LLM ran · All events persisted to MongoDB with full trace, SHAP values, and jury reasoning.
